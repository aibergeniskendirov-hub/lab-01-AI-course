# Декларация об использовании ИИ

**Инструмент:** Claude (Sonnet 5) через Claude Code CLI — агент, работающий
в терминале на моём компьютере в интерактивном режиме: каждое действие
(команда, установка пакета, запуск скрипта, git-операция) выполнялось по
моему запросу и требовало моего подтверждения перед выполнением. Ниже
описано, что именно я поручал ИИ и что делал сам.

**Что именно использовалось и для чего:**

1. **Настройка окружения.** По моей команде ИИ склонировал репозиторий
   лабораторной, создал виртуальное окружение Python и установил `tiktoken`
   и `python-dotenv` (для Part 2, требующего `anthropic>=1.0` и Python
   3.10+, реального запуска не было — ключ с проектора не был получен, см.
   ниже). Каждый шаг я подтверждал лично.
2. **Запуск скриптов.** По моему запросу ИИ выполнил `part0_tokenizers.py`,
   `part1_offline.py` и `part3_cost.py` (последний — на
   `measurements.example.json`, эталонных данных из репозитория, поскольку
   реальный ключ Anthropic для Part 2 в аудитории на момент подготовки
   получен не был; README лабораторной прямо допускает такой вариант).
3. **Объяснение механики.** ИИ объяснил построчно логику `cost_usd()`,
   `request_input_tokens()` и разницу между `input-token ratio` и
   `total-bill ratio`, а также механику BPE-токенизации и причину, по
   которой кириллица и казахские буквы (ә ғ қ ң ө ұ ү һ і) обходятся дороже
   английского.
4. **Черновик итоговой страницы.** ИИ составил черновик текста
   (`ANSWERS.md`) на основе фактически полученных числовых результатов
   запусков скриптов — числа не выдуманы ИИ, они взяты из вывода
   `part0_tokenizers.py`, `part1_offline.py` и `part3_cost.py`.
5. **Публикация.** Аккаунт GitHub на университетской почте, вход через
   `gh auth login` и финальный push в репозиторий выполнены лично мной.

**Что сделано самостоятельно:** прочитан код всех шести файлов лабораторной
(`texts.py`, `prices.py`, `part0`–`part3`), проверено воспроизведение чисел,
принято решение по объёму нагрузки, по рекомендации модели для
продакшн-очереди и по формулировке аргументов качества/цены — эти выводы
являются собственным суждением, а не сгенерированы ИИ без проверки. Студент
готов устно объяснить любую строку кода и любое число в отчёте.

**Ограничение:** Part 2 (реальный вызов Claude API с измерением ответов на
трёх языках) не был выполнен лично из-за отсутствия ключа с проектора на
момент подготовки; при наличии ключа `measurements.json` будет
перегенерирован командой `python3 part2_measure.py --call`, а числа в
`ANSWERS.md` — обновлены.
